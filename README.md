# Ресторант „Терасата“ — проект на GitHub Pages

## URL адреси без .html
`/`, `/menu/`, `/obedno-menu/`, `/praznenstva/`, `/galeria/`, `/kontakti/`, `/admin/`.
Във всяка папка има `index.html` (технически файл, не част от публичния адрес).
Старите `*.html` линкове остават като пренасочвания.

## Структура
- `assets/css/` — стилове
- `assets/js/` — сайт, съдържание, локален редактор, A4 генератор
- `assets/images/` — оптимизирани реални снимки, SVG орнамент
- `docs/` — спецификация и решения
- `archive/` — стари документи и оригинални снимки
- `admin/` — **демо редактор**, без защитен вход

## Хостинг
GitHub → Settings → Pages → Deploy from a branch → main → /(root).
Работи със собствен домейн или GitHub Pages project path /Terasata/.
Без PHP и .htaccess.

## Публикуване
В /admin/ данните са в localStorage **само на този браузър**.
За публично публикуване замени `assets/js/content.js` с експортирания
файл от „Архив и експорт“. Пази JSON резервни копия и оригинални снимки.
Черновите не се пренасят автоматично при смяна на домейна.

**ВНИМАНИЕ:** /admin/ на GitHub Pages е публично достъпен; това НЕ е
защитен сървърен администраторски панел. Не въвеждай пароли и лични данни.
Реални роли, сигурност и централизирано публикуване изискват бекенд.

Оригинален файл на логото все още не е предоставен.
