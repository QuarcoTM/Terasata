# Терасата — защитен PHP/MySQL модул

**В процес на подготовка.** PHP/MySQL не се изпълняват от GitHub Pages; сървърният модул не е активиран.

## Внедряване
1. PHP 8.3, MySQL 8, HTTPS; разширения PDO MySQL, GD, mbstring, fileinfo.
2. Създайте отделна празна MySQL база и DB потребител.
3. Задайте като сървърни environment variables: TERASATA_DB_HOST, TERASATA_DB_NAME, TERASATA_DB_USER, TERASATA_DB_PASSWORD. Не ги качвайте в GitHub.
4. По SSH/CLI изпълнете от корена: php backend/bin/setup.php owner@example.com. Изисква се парола от минимум 12 символа, която не се показва при въвеждане.
5. Направете media/ writable за PHP и проверете забраната за изпълнение на PHP, HTML и SVG в тази папка.
6. Отворете по HTTPS /backend/panel/index.php. Проверете вход, изход, роли, запис, качване, изтекли сесии и публични API отговори.
7. Едва след успешния тест включете window.TERASATA_BACKEND_ACTIVE=true в assets/js/backend-mode.js.
8. Преди реален старт спрете публичния /admin/ демо редактор.

## Вградени защити
- password_hash/password_verify; сървърна сесия с HttpOnly, Secure и SameSite Strict; таймаут при бездействие.
- CSRF защита, ограничаване на опити за вход, SQL prepared statements.
- Owner/editor права по секции, проверявани на сървъра.
- Контрол на версиите и HTTP 409 при паралелни редакции.
- Декодиране и презаписване на изображения като WebP; ограничен размер и формат.
- Публичният API не връща чернови на новини или обедно меню.

## Остава преди production
Интеграционни тестове на жив PHP+MySQL хостинг, регулярно резервно копие на базата и media/, тест на възстановяване, преглед на CSP и 2FA по избор за главния администратор.
Прехвърляйте локални данни само с резервен JSON архив; никога пароли.
Без хостинг този модул НЕ е истински работещ онлайн админ.
Главният администратор може да създава, спира и активира служители, да променя разрешенията им и да задава нова парола.
