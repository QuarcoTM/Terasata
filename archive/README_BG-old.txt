РЕСТОРАНТ „ТЕРАСАТА“ — ВИЗУАЛНА ВЕРСИЯ 3
========================================

КАК ДА КАЧИТЕ В GITHUB
----------------------
1. Разархивирайте ZIP файла на компютъра.
2. Отворете вашето GitHub хранилище.
3. Add file → Upload files → качете ВСИЧКИ файлове от архива директно в корена.
4. Commit changes. Приемете замяната на старите HTML/CSS/JS и снимки.
5. Ако ползвате GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
Няма подпапки. Не качвайте самия ZIP файл — само съдържанието му.

ВИЗИЯ
------
- Изработена е реална структура HTML/CSS, без нарязване на концептуалната картинка.
- Топла кремаво-бежова цветова схема и златисти детайли.
- Ръчно изрисуваното leaf-ornament.svg е САМО декоративен листен орнамент, не снимка.
- Всички фотографии *.webp са оптимизирани копия на РЕАЛНИ снимки, изпратени от ресторанта.
- Начална: голяма снимка, обедно меню (само когато има публикувано), категории,
  празненства и събития, актуално (само при публикации), галерия, контакти.
- „Нашите пространства“ са преместени в страницата „Празненства и събития“.
- Категориите са седем, точно по предоставеното меню плюс „Салати“.
- Няма категории „Напитки“ или „Десерти“.
- Няма номерации пред категориите. Иконите са SVG, изчертани чрез HTML/JS.
- От началната категориите водят към menu.html?cat=...
- В страницата menu.html натискането на категория СМЕНЯ съдържанието на същото място,
  без да превърта надолу към секции.

НЕЩА, КОИТО ЩЕ СЕ ПОПЪЛНЯТ СЛЕДВАЩИЯ ЕТАП
----------------------------------------
- Реалните и актуални артикули, грамажи и цени от постоянното меню.
- Ежедневното обедно меню: въвеждане през бъдещия админ панел.
- Реални актуални новини и предложения.
- Оригиналният фирмен файл на логото (ЗАСЕГА временно има типографски надпис
  „Терасата“, без опити за копиране/възстановяване на оригиналния знак).
- Административният панел, служебните профили и индивидуалните им права.
- Генераторът на изображение за обедното меню за Facebook.
- QR менюто, предвидено за по-късно.
