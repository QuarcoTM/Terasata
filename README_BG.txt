ТЕРАСАТА — ПЪРВА РАБОТЕЩА ВЕРСИЯ НА САЙТА
=========================================
Статус: визуална и функционална основа, НЕ готов за публично публикуване.

КАК ДА ОТВОРИТЕ САЙТА
----------------------
1. Разархивирайте ZIP файла изцяло.
2. Отворете index.html през браузър на компютър.
3. Всички HTML, CSS, JavaScript и снимки са на ЕДНО ниво, без вложени папки.
4. За проверка през локален уеб сървър може да ползвате: python -m http.server 8000

КАКВО РАБОТИ
-----------
- Отделни HTML страници: начална, меню, обедно меню, празненства, галерия, контакти.
- Навигация за мобилен телефон и компютър.
- Оригинални реални снимки от потребителя (отделни файлове, без AI снимки).
- Филтри на галерията, увеличаване на снимки и затваряне с Escape.
- Бутони за директно телефонно обаждане.
- Facebook/Instagram и Google Maps линкове.
- Логика за обедно меню: само делнични дни, само при публикувано меню за текущата дата.
- Логика за новини: показват се само одобрени и активни публикации.
- Постоянното меню е подготвено с правилните 7 категории.

КАКВО УМИШЛЕНО ОЩЕ НЕ Е АКТИВИРАНО
---------------------------------
- Реалното постоянно меню с ястия, грамажи и цени (нужно е окончателно потвърждение).
- Дневните обедни менюта (не публикуваме старо меню като днешно).
- Новини и промоции (няма предоставени конкретни текущи публикации).
- Административен панел, потребителски роли и 2FA.
- Автоматично генериране на Facebook визия за обедното меню.
- Оригиналното лого (няма качествен файл; текстовият надпис в заглавната лента е ВРЕМЕНЕН и не е имитация на лого).
- QR меню (по желание ще бъде добавено в бъдеща версия).
- Хостинг, домейн, постоянна база данни и публикуване.

ВАЖНО
-----
- Никога не режете концептуалното изображение на сайта. Всички елементи в проекта са отделен HTML/CSS, а всички използвани фотографии са отделни файлове.
- IMG_*.jpeg са предоставените оригинални фотографии.
- *.webp са технически оптимизирани копия, не генерирани изображения.
- След одобряване на визията и съдържанието ще разработим защитен админ панел със сървърно съхранение на данните. Не публикувайте временно управлявани данни директно от JavaScript като окончателно решение.
- Публичният достъп и индексирането трябва да се включат след пълни тестове и избор на домейн/хостинг.

GITHUB — КАЧВАНЕ БЕЗ ПАПКИ
--------------------------
1. Разархивирайте terasata-github-flat.zip на вашия компютър.
2. В GitHub отворете хранилището и изберете Add file → Upload files.
3. Маркирайте файловете ВЪТРЕ в разархивираното място и ги влачете/качете наведнъж.
4. Натиснете Commit changes. Не качвайте самия ZIP — GitHub не го разархивира.
5. За GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.
